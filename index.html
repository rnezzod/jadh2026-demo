Causal structures in historical texts interactive demo · JADH2026 poster

Node fill = perspective: agent patient cause | Ring = presupposition: justified unjustified neutral | Edge = relation: direct cause enabling motivation width = strength · dashed = contingency · size = number of links | Click an event to see its textual evidence and open its causal story.
Demo for the JADH2026 poster “An LLM-Based Tool for Extracting and Visualizing Causal Structures in Historical Texts” (Takahashi, Toda, Sahara; COTEN Inc.). Layout: events in temporal order; rows are causal chains. Source texts: Japanese and English Wikipedia (CC BY-SA 4.0); extraction and classification: gpt-5.4, temperature 0. Outputs are one LLM-mediated reading of each text, not ground truth.
